# PocketPlan 💰

**PocketPlan** is a simple personal budgeting and expense-tracking app designed to help people manage their money and build better spending habits.

## Features

* Set a personal spending budget
* Record daily expenses
* Track total spending and remaining budget
* Review and manage recent expenses
* Simple, mobile-friendly interface
* Progressive Web App (PWA) installation support

## Purpose

PocketPlan aims to help students and people on tight budgets understand where their money goes and make more informed spending decisions.

## Technologies

* HTML
* CSS
* JavaScript
* Progressive Web App technologies

## Getting Started

Open `index.html` in a browser to run the app locally.

## Future Improvements

* Expense categories
* Weekly and monthly reports
* Persistent data storage
* Optional spending reminders
* Secure user accounts and cloud synchronisation

## Project Status

PocketPlan is an MVP under development. Features and functionality may change as the project evolves.
